# Tube Ultimate Player v0.2.20

v0.2.20 主要完善了 Linux 平台支持，并正式加入 Fedora RPM 打包与 COPR 软件仓库发布流程。

## 主要更新

- 新增 Fedora 43 和 Fedora 44 RPM 软件包
- 新增通过 GitHub Actions 自动构建 RPM 的工作流
- 新增自动提交源码 RPM 至 Fedora COPR 的发布流程
- 新增 Linux 原生启动脚本
- 新增 Linux 桌面应用入口
- 新增应用图标安装支持
- 改进 Linux 平台下的运行目录和资源路径处理
- 改进 PySide6、QtAwesome、yt-dlp、FFmpeg 和 libmpv 依赖配置
- 在提交 COPR 前自动验证源码 RPM 和二进制 RPM
- Fedora 软件包不再包含 Windows 专用的 DLL 和 EXE 文件
- 改进 Linux 打包、构建和发布文档
- 修复 Fedora COPR 仓库生成及发布流程中的相关问题

## Fedora 安装方式

首先启用 COPR 软件仓库：

```bash
sudo dnf copr enable davidzhao/Tube_Ultimate_Player
