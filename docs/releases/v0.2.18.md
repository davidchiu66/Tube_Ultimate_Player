# v0.2.18

`0.2.18` 调整 Linux 发布策略，取消增强 AppImage/DEB 的正式发布构建，改为面向 Fedora 系发行版提供 RPM 打包与 Fedora COPR 发布工作流。

## 发布策略调整

- 取消 Linux 增强 AppImage/DEB 发布构建
- GitHub Release 不再上传 Linux 增强 AppImage/DEB 产物
- Windows 普通版与增强版发布流程保持不变

## Fedora RPM 与 COPR

- 新增 Fedora RPM spec 与 RPM 启动器
- 新增 `release-linux-rpm-copr.yml` 工作流
- 支持构建 SRPM/RPM 并上传构建产物
- 支持通过 `COPR_CONFIG` secret 提交 SRPM 到 Fedora COPR
- 支持通过 `COPR_PROJECT` 与 `COPR_CHROOTS` 配置 COPR 目标项目和 chroot

## 文档与测试

- 更新 README 中的 Linux 发布说明
- 更新 Linux 构建与发布文档
- 补充 RPM packaging 单元测试
