# v0.2.19

`0.2.19` 聚焦播放器交互、播放列表入口、缩放适配与缩略图稳定性，补足了一批日常使用里最容易遇到的卡点。

## 播放器交互优化

- 修复窗口模式与全屏切换时，控制面板在特定鼠标位置下可能持续停留在滑入状态的问题
- 新增 `Esc` 作为退出全屏快捷键
- 新增 `Z` / `X` 作为播放速度增减快捷键，并在达到边界时保持当前值不变
- 使用快捷键调整音量或倍速时，会在屏幕中央显示半透明提示，并在短暂延时后自动消失

## 播放列表与导航

- 顶部工具栏新增明确的“播放列表”按钮，放置在“首页”和“播放器”之间
- 播放列表页面改为与下载列表、收藏、历史一致的统一表格风格
- 新增已保存播放列表下拉选择、加载与删除入口
- 修复手动选择已保存列表后，“加载”按钮未及时启用的问题

## 设置页与界面适配

- 常规设置页改为可滚动布局，避免较小分辨率或较高缩放下无法访问完整设置项
- 优化高 DPI / 屏幕缩放场景下的初始窗口尺寸与工具栏紧凑模式切换
- 在 125% 等缩放比例下，应用会更积极地收敛到当前屏幕可用区域内显示

## 稳定性与细节

- 缩略图加载新增网络错误、HTTP 状态、内容类型与图片完整性校验
- 避免损坏或截断图片响应触发 `libpng error: Read Error`
- 改进多行标题省略逻辑，减少中文、英文和窄宽度场景下的断行异常

## 测试与验证

- 新增播放列表页面、DPI 适配、缩略图完整性等回归测试
- 当前版本已通过完整单元测试集验证
